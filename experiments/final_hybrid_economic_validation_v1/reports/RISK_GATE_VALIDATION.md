# Decision-risk gate validation

Task A's main risk target is LightGBM regret, matching the pre-existing static task assignment; Task B's is PPML regret. A separate Task A blend-risk model is labeled sensitivity. Predictions are clipped at zero as in the prior gate. Risk values are regret estimates, not probabilities. High-regret event cutoffs are the OOF training-period 80th percentiles, frozen for each outer origin.

## Clipping and ties

Ridge regret predictions are clipped at zero. The resulting zero mass and tie groups are material for some task-year fits. Fixed operational gates accept every pool tied at or below the threshold, which can materially overshoot nominal coverage; they do not break cutoff ties. The separate matched-coverage diagnostic uses HS2 as a deterministic secondary order. These are regret scores, not probabilities.
